# İSG Ara Sınav Çalışma Sitesi

Hafta 1–7 (mevzuat, yönetmelik/tebliğ, iş kazası, meslek hastalığı, fiziksel/kimyasal/biyolojik risk) + makine mühendisliği odaklı notlar, flash kartlar ve mini test. Tek dosya: `index.html`, dış bağımlılık yok.

## GitHub Pages ile yayınlama
1. github.com → **New repository** → ad: `isg-calisma` → Public → Create.
2. **Add file → Upload files** → `index.html` (ve istersen bu README) sürükle → Commit.
3. **Settings → Pages** → Source: *Deploy from a branch* → Branch: `main`, klasör `/ (root)` → Save.
4. 1–2 dk sonra: `https://<kullanıcı-adın>.github.io/isg-calisma/` — telefonda aç, "Ana ekrana ekle" de.

İlerleme işaretleri, bilinen kartlar ve en iyi test skoru telefonun tarayıcısında saklanır.
